Gmail

  1. Settings (gear) → See all settings.
  2. General → Signature → Create new.
  3. Click in the box and paste (Ctrl/Cmd + V).
  4. Set it as default for new emails and replies. Save changes.

Outlook

  1. Settings → Mail → Compose and reply.
  2. New signature, give it a name, paste.
  3. Choose it for new messages and replies. Save.

Phone (Gmail app)

  1. The app only takes plain text.
  2. Use: Name · Role · Virgo Point Capital · phone.
  3. Desktop signature still applies to replies sent from the web.
